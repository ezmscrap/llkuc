## 7.3功績ポイントの計算

功績ポイントには、個人功績ポイントと部隊功績ポイントがあります。

個人功績ポイントは、個人ごとにカウントされます。

| 個人の功績 | 個人に与えられる功績点 |
| --- | --- |
| 作戦への功績 |  |
| 　所属部隊が作戦に成功 | 1.5 |
| 　所属部隊が作戦に失敗 | 1 |
|  |  |
| 撃墜に応じた功績 |  |
| 　上位機体を撃墜 | 1.5／機 |
| 　同等機を撃墜 | 1.0／機 |
| 　劣等機を撃墜 | 0.5／機 |
| 　艦船を撃沈 | 4.0／隻 |
| 　戦術目標 | 4.0／個 |
|  |  |
| 部隊貢献に応じた功績 |  |
| 　生死に関わる支援 | 1.0／回 |
| 　一般的な支援 | 0.5／回 |
|  |  |
| 戦略に関する功績 |  |

　敵の戦略情報を取得8.0
