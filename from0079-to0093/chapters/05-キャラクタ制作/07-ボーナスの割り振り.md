## 5.7ボーナスの割り振り

ボーナスとは、指針と経歴により決定された能力、技能にそのキャラクタ独自の特徴をつけるために使うことのできる得点(練度)のことです。通常のキャラクタは5点の練度を、自由に好きな能力と技能に振り分けることができます。

また、この得点はゲームマスターのさじ加減で上下させても構いません。目安としては表9を利用してください。基本的に全てのPCのボーナスの合計が[PCの人数×5]が妥当です。

表9.ボーナスとキャラクタの特異性

| キャラクターの特異性 | ボーナス |
| --- | --- |
| ザコキャラクター | -5 |
| 不利なPC | ±０ |
| 一般PC | +5 |
| ボーナス付きPC | +10 |
| 主人公特典 | +20 |
